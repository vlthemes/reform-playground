# ReForm demo on WordPress Playground

[Open the demo](https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fraw.githubusercontent.com%2Fvlthemes%2Freform-playground%2Fmain%2Fblueprint.json)

A WordPress site in your browser with [ReForm](https://wordpress.org/plugins/reform-contact-form/) and three ready forms. Nothing is installed anywhere.

These files are built by `npm run build:playground -- https://raw.githubusercontent.com/vlthemes/reform-playground/main/` in the plugin's repository; don't edit them here.
